# Portación experimental de Familias

Este proyecto es una copia experimental de WebResponsables. Estamos modernizando la interfaz de Blade/AdminLTE a React con Eureka UI, tomando el sistema Pranzo como referencia general y manteniendo Laravel como backend.

La migración es gradual, conservando las funciones existentes y ajustando el trabajo con las devoluciones del usuario. Laravel ya se actualizó a la versión 13 y las pantallas principales del portal están en React/EureUI; Rematriculación permanece en Blade.

En paralelo, registramos lo aprendido en un prompt reutilizable para otras portaciones. Si el resultado se valida, esta copia podrá reemplazar al proyecto original.

El primer cliente definido es IFES Neuquén, con identidad y archivo de colores propios.

Decisión del 2 de noviembre de 2026: esta entrega alcanza solamente IFES. La app móvil debe seguir funcionando igual; sus APIs, vistas Blade y recursos no forman parte de la portación. Revisar consumidores móviles antes de retirar código compartido. No se incluye Rematriculación de Cultural.
